1. Chapter 5 — Key takeaways

1. Closure = a function remembering its lexical scope even when called outside it.
2. Closures happen automatically whenever you pass inner functions out of their outer function.
3. The closed-over scope stays in memory as long as the inner function has a reference to it.
4. Every time, event handler, callback, promise handler uses closure — it's everywhere!
5. for-loop with let creates a new binding per iteration — the modern closure fix.

Mistake
for-loop with var: all callbacks share the SAME variable — classic bug!
